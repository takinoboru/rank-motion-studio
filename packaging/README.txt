RANK / MOTION v@VERSION@
====================

中文
----
1. 解压整个 ZIP，不要只打开压缩包内的文件。
2. macOS：双击 start-macos.command。
   Windows：双击 start-windows.bat。
   Linux：运行 ./start-linux.sh。
3. 启动器会在 http://127.0.0.1:8765/ 打开编辑器。保持终端窗口运行；关闭终端或按 Control+C 即可停止。
4. 如果电脑没有 Python 3，启动器会直接打开 index.html。编辑功能仍可使用，但为保证 WebCodecs 视频导出正常，建议安装 Python 3 后使用本地服务器启动。
5. 工程保存在浏览器本机。请使用“保存工程”导出 JSON 备份。

English
-------
1. Extract the entire ZIP instead of opening files inside the archive.
2. macOS: double-click start-macos.command.
   Windows: double-click start-windows.bat.
   Linux: run ./start-linux.sh.
3. The launcher opens the editor at http://127.0.0.1:8765/. Keep the terminal window open; close it or press Control+C to stop.
4. If Python 3 is unavailable, the launcher opens index.html directly. Editing still works, but running the local server is recommended for reliable WebCodecs video export.
5. Projects are stored in the local browser. Use “Save Project” to export a JSON backup.

日本語
------
1. ZIP 内のファイルを直接開かず、ZIP 全体を展開してください。
2. macOS：start-macos.command をダブルクリックします。
   Windows：start-windows.bat をダブルクリックします。
   Linux：./start-linux.sh を実行します。
3. ランチャーが http://127.0.0.1:8765/ でエディターを開きます。ターミナルを起動したままにし、終了するにはウィンドウを閉じるか Control+C を押します。
4. Python 3 がない場合は index.html を直接開きます。編集機能は使用できますが、WebCodecs による動画書き出しを安定させるにはローカルサーバーでの起動を推奨します。
5. プロジェクトはブラウザー内に保存されます。「プロジェクトを保存」から JSON のバックアップを書き出してください。
