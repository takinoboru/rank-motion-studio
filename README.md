# RANK / MOTION

一个以 p5.js 渲染的漫画排名动画编辑器。参考双描边胶囊姓名框、黑色名次章、错列、倾斜和厚阴影的排名形式。

## 使用

直接打开 `dist/index.html` 即可编辑。推荐通过 HTTPS 网站或本地 HTTP 服务使用视频导出，WebCodecs 需要安全上下文。网页内「使用指南」介绍全部操作。

- 左侧编辑 1–30 位选手；姓名、积分、单人样式、字体与全局参数均可修改。
- 全局排列可调整位置、倾斜、旋转、错列、行距；姓名框可调整圆角、双描边、填充、阴影和点阵。
- 每位选手可分别设置姓名色、积分色、名次文字色、字号、入场方式、延迟、透明度、位置、缩放等。
- 选中属性按 K 或点击 ◇ 添加关键帧；拖动菱形改时间，双击编辑值与贝塞尔曲线。文字与开关采用保持插值。
- 分数关键帧触发自动排名交换，积分逐位滚动；平分时按选手列表顺序。隐藏的选手仍参与排名。
- 自动换位的时间检测精度为 1/240 秒，交换时长与曲线可在全局动画中设置；播放和拖动使用同一套确定性计算。
- 默认动画在 2–6 秒使「うなぎポテト」从 13pt 增至 26pt。
- 本机自动保存、JSON 导入/导出、撤销重做。字体文件只保留在当前页面，换设备或刷新后需重新载入；JSON 不含字体。
- 姓名及积分太长时会自动缩小，以避免溢出姓名框。位置单位基于 1920×1080 设计空间。

## 导出

- 分辨率最高 3840×2160，另有竖屏 2160×3840 与方形。24 / 25 / 30 / 50 / 60 fps。
- WebM 逐帧输出使用 WebCodecs VP9 或 VP8，调用 `isConfigSupported` 检查当前设备；时间戳按所选帧率生成。渲染速度和实时预览帧率无关。
- 实时 WebM 录制使用 MediaRecorder，实际帧率受性能与浏览器调度影响。
- PNG 序列可保留透明背景。每 60 帧或约 96MB 打一个 ZIP 分包，另下载帧率说明；请允许浏览器多文件下载。取消时已下载的分包仍可保留。
- PNG 当前帧按合成分辨率输出。合成时长最高 120 秒，可选择局部输出。
- 视频保存在浏览器内存中，长片可分段输出。4K60 视频取决于设备编码能力；不支持时请选择 PNG 序列或较低规格。
- 竖屏/方形合成默认完整容纳 16:9 设计空间，可通过全局缩放、位置和排列重新构图。

## 文件

`dist/engine.js`：插值、积分、排名交换、p5/Canvas2D 绘图核心。

`dist/app.js`：中文编辑界面、关键帧、贝塞尔控制、工程与导出。

`dist/vendor/`：本地固定版本 p5.js 1.11.11、webm-muxer 5.1.4、fflate 0.8.2，避免核心功能依赖 CDN。内置 Noto Sans JP 与 Barlow Condensed 开源字体；无需在线字体服务。

## 验证范围

已验证积分插值、并列与降分、四次换位、交换连续性、确定性跳转、颜色与保持插值、全局继承、4K 原生画布渲染、透明像素、长姓名与最大积分、工程校验与关键帧合并。另以模拟编码器验证 4K60 的帧数、时间戳、时长、资源关闭及取消路径。

没有执行浏览器交互测试或实际硬件视频编码测试。WebMCP 在支持的页面中注册工程读取与积分动画创建工具；当前环境没有支持的 WebMCP 验证上下文，未验证工具注册。
